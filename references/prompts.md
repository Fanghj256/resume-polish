# 提示词库

五个环节的提示词模板，按流程顺序编号。**把【】占位替换后使用**；每条后面的"使用要点"是实战踩出来的，别跳过。

---

## 1. 建立简历衣柜（经历建档）

**用途**：流程起点，唯一的"事实入口"。一次建好，之后每条新经历、每个新数字都往里加。

```text
我会提供我的全部经历，包括实习、科研、项目、竞赛、学生工作、社团、志愿和兼职。
请把它们整理成结构化档案，每条包含：时间段｜组织｜角色｜任务背景｜我的具体动作｜可量化结果｜使用的方法与工具｜可迁移能力标签
要求：1. 严格只使用我提供的原始信息，不得新增数字、头衔或成果；2. 不确定的地方用【待补充】标出，并告诉我需要补充什么；3. 最后按「与求职相关的程度」排序，并提示我经历结构里还缺什么。
我的经历如下：（逐条粘贴，或者是导入文件、数据）
```

**使用要点**：
- 输入可以是逐条口述、粘贴旧简历，或直接指一个文件夹让 agent 自己读；**扫描件与图片必须实际看图**，不能把空文本当作没有经历。
- 建完必须做两件事：① 把【待补充】集中问一轮（每轮优先 1–3 个最关键的问题）；② 之后每个新事实都按「记衣柜：…」回写。
- 产出固定命名 `简历衣柜.md`（放用户资料目录，不进 Skill 目录）。

## 2. 拆解 JD（校园招聘视角）

**用途**：拿到一个岗位后的第一件事。先让 HR 视角把 JD 拆开，再决定简历怎么定制。

```text
你是一位有8年经验的校园招聘HR，熟悉[行业]的用人标准。以下是我要投递的岗位JD：【粘贴JD全文】
请完成以下四件事：1. 提炼这个岗位真正在意的5项核心能力，按重要性排序，并说明JD里哪句话支撑你的判断；2. 列出HR筛简历时会出现的关键词，包括工具、方法、指标、行业术语；3. 区分硬门槛（学历/专业/技能/时间要求）和加分项；4. 指出JD中含糊或前后矛盾的地方，以及我应该在简历里重点回应的内容。
请用表格输出。
```

**使用要点**：
- `[行业]` 要填具体赛道（互联网/游戏、金融监管、国企综合管理…），别留空。
- **JD 全文粘全**，含"任职要求""实习时长""工作地点"等段落；只粘职责会漏掉硬门槛判断。
- 拆完**存成文件**（`01_JD拆解.md`），后面打分与质检都要引它。

**可选追加（对照衣柜，直接落到选材）**：

```text
另外，请对照我的「简历衣柜」逐项核对：这个岗位的 5 项核心能力里，我已有哪几条可用的经历证据（写明是哪一条经历、哪几个数字），哪几条目前没有证据。
```

## 3. 经历与岗位匹配度打分

**用途**：定下"哪几段上、按什么顺序上、哪些删"，再动笔排版。

```text
这是目标岗位的JD与核心能力要求：【粘贴JD或第2步的拆解结论】
请完成：1. 逐条评估每段经历与该岗位的匹配度（1-5分），并说明理由；2. 筛出最该放进简历的3-5段经历，并给出建议排列顺序；3. 标出与岗位无关、可以删掉或压缩成一行带过的经历；4. 指出JD中有哪些要求在经历档案里找不到证据，以及我现在可以怎么补。
```

**使用要点**：
- 输入尽量用**第 2 步的拆解结论**（5 项核心能力＋硬门槛/加分项），比只给原始 JD 打得准。
- 「经历档案」指 `简历衣柜.md`——取事实只看它，别凭记忆。
- 产出 **markdown + Excel 两份**：序号用跨岗位稳定的经历编号（如 `E01`–`E10`）；表格列：序号｜经历｜类别｜匹配分｜建议（上/压/删）｜采用(是/否)｜简历顺序｜理由｜对应能力。
- **请用户只改 Excel 的「采用」「简历顺序」两列**，改完回传。
- ⏸ **打完分就停**：等用户回传勾选结果再进入第 4 条（写成条目）。不要替用户选材，也不要提前生成简历、导出 PDF——用户可能想换掉某条或整个跳过。

**可选追加（把评分锚点定死）**：

```text
评分锚点请按这个标准：5＝有直接对应的经历且有可写数字；4＝有同类动作的迁移证据；3＝间接相关；2＝只能占位、面试问不出细节；1＝无证据。每条评分后写明对应的是衣柜里哪一条。
```

## 4. 把经历写成简历条目

**用途**：把选中的经历压成简历能用的条目。

```text
【粘贴原始经历，例如：负责公众号运营，做了几场活动，涨了粉】
要求：1. 每个版本不超过3行，使用STAR结构，动词开头；2. 优先使用我提供的原始数据，不得编造、放大或四舍五入；3. 如果缺少结果数据，请用【此处建议补充具体数字，如阅读量/转化率/参与人数】提示我，而不是替我编一个；4. 去形容词，少用「负责」「参与」这类模糊动词。
```

**使用要点**：
- 原始经历**从衣柜整段贴**，不要凭记忆复述。
- "不超过 3 行"是上限，单页 A4 实际只能 **1–2 行**（实测：1 行 ≈ 4.6mm，2 行 ≈ 9.1mm，一个项目标题行 ≈ 5.1mm）。压行时先压最长的那条。
- STAR 的 S/T 在单页简历里用**能力标签**承担，正文只写 A（动作）和 R（结果）——正好对上模板的 `<b>能力标签：</b>动词开头…结果` 体例。
- 缺数字处标【建议补充】，与衣柜的【待补充】同一套约定。

**可选追加**：

```text
每条后面再标注两件事：① 它对应目标 JD 的哪项核心能力；② 用到的数字来自经历档案的哪一条，便于我回溯核对。
```

## 5. 投递前的 AI 质检

**用途**：最后一道闸——成稿之后、点投递之前跑。

```text
你是一位严格的校招简历质检员。请检查我即将投递的简历：目标 JD：【粘贴】简历内容：【上传或粘贴】请完成：1. 检查错别字、标点、时间格式、中英文混用、第一人称、空话和模糊动词；2. 标出所有数字，逐一问来源、口径，判断数据合理性、能否面试复述；3. 对照 JD，指出缺证据的关键词和易被误读表述；4. 检查敏感信息；如有，先提醒删除，不继续输出；5. 给出“必须改/建议改/可不改”清单，不编造经历或数字。
```

**使用要点**：
- **贴原始 JD 全文**（不是拆解结论）——要求 3 要用 JD 的原词比对关键词。
- **把衣柜的数字口径表一起贴进去**，要求 2 才能真判断口径自洽（同一数字在不同版本/文件里打架是最常见的问题）。
- **要求 4 会"熔断"**：简历正常带手机号和邮箱，它可能一到敏感信息就停下不再往下输出。建议加一句限定：

```text
手机号与邮箱是必要的联系方式，不属于需要删除的敏感信息；请重点检查身份证号、家庭住址、家人信息、公司内部资料、他人隐私等。
```

- 要求 1 与第 4 步的标准重叠（去形容词、少用"负责/参与"）：以第 4 步的口径为准，别被质检拉回去反复改。
- 给出"必须改"之后，**改完要再跑一次**——尤其是动了数字或时间。
- 质检挖出的"缺证据的关键词""面试复述不了的数字"要**回写衣柜**，形成闭环。

**可选追加**：

```text
上面第 2 点里请额外标注：每个数字对应我经历档案的哪一条、是否存在新旧口径冲突。
```

## 用法串联

```text
【一次性建立 · 之后持续维护】
1. 建立简历衣柜 ← 所有事实的唯一入口；新经历、新数字按「记衣柜：…」回写
        ↓
【每投一个岗位跑一遍】
2. 拆解 JD → 5 项核心能力 + 硬门槛/加分项 + 关键词
        ↓ 把 2 的结论整段作为输入
3. 匹配度打分 → 定下上哪 3-5 段、什么顺序、删谁
        ↓ 把选中的经历从衣柜整段贴进去
4. 写成条目 → 1-2 行的简历条目（缺数字处标【建议补充】）
        ↓ 填进模板，预览成稿（数字口径对衣柜口径表）
5. 投递前质检 → 错字/数字/敏感信息/缺证据清单
        ↓ 改完再导一次终版 PDF，然后才投递
```
